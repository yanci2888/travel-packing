# packing-reference.md - 打包判斷標準

此文件定義行李計算的靜態資料規則，所有物品判定必須依據此標準執行。

### 1. 基本數量計算
- 貼身衣物 (上衣/內著/襪子)：{出遊天數} + 1 套。
- 下著 (褲/裙)：{出遊天數} / 2 套 (無條件進位)。

### 2. 氣候比對規則
- 低於 10°C：必備發熱衣、羽絨/防風厚外套、毛帽手套。
- 10°C ~ 18°C：必備薄長袖、風衣/一般外套。
- 19°C ~ 25°C：短袖搭配薄外套。
- 高於 25°C：短袖、防曬乳、太陽眼鏡。
- 降雨指標：降雨機率大於 30% 需加折疊傘；大於 60% 需加註預警攜帶防水鞋。

### 3. 情境與基礎設施比對
- 住宿為青旅/露營：必須納入「盥洗旅行組、毛巾、牙刷」。
- 行程含玩水/海島：必須納入「泳具、海洋友善防曬乳、防水袋」。
- 插座不符：必須納入「萬用轉接頭」。
- 廉航 (LCC)：必須建立 ### 安檢限制 區塊，標註液體 100ml 與透明夾鏈袋規範。

### 4. 格式標準
大盤整理格式必須嚴格依照以下 H3 (###) 標題分類，不得自行編造欄位：
`### 衣物穿搭`
`### 3C 與轉接裝備`
`### 盥洗與日用品`
`### 隨身重要物品`
